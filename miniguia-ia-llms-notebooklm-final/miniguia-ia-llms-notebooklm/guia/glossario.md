# Glossário --- IA Generativa e LLMs

  -----------------------------------------------------------------------
  Termo                               Explicação
  ----------------------------------- -----------------------------------
  Inteligência Artificial             Área relacionada ao desenvolvimento
                                      de sistemas capazes de realizar
                                      tarefas associadas à inteligência.

  IA Generativa                       Tecnologia capaz de gerar novos
                                      conteúdos a partir de padrões
                                      aprendidos.

  Machine Learning                    Abordagem em que sistemas aprendem
                                      padrões a partir de dados.

  Deep Learning                       Abordagem baseada em redes neurais
                                      profundas.

  LLM                                 Large Language Model, modelo de
                                      linguagem treinado para prever
                                      tokens e gerar conteúdo.

  Token                               Unidade utilizada pelo modelo para
                                      representar partes do texto ou
                                      outros elementos processáveis.

  Tokenizer                           Componente que divide/transforma
                                      uma entrada em tokens.

  Token ID                            Identificador numérico associado a
                                      um token.

  Transformer                         Arquitetura de rede neural usada em
                                      muitos LLMs.

  Pesos                               Parâmetros numéricos aprendidos
                                      durante o treinamento.

  Janela de contexto                  Quantidade de tokens considerada
                                      pelo modelo em uma interação.

  Prompt                              Instrução ou entrada fornecida ao
                                      modelo.

  Inferência                          Execução de um modelo treinado para
                                      produzir uma saída.

  Alucinação                          Geração de informação incorreta ou
                                      inventada com aparência de
                                      confiança.

  Stateless                           Sem manutenção automática de
                                      memória entre requisições.

  Temperatura                         Parâmetro que influencia a
                                      variabilidade das respostas
                                      geradas.

  SFT                                 Supervised Fine-Tuning, etapa de
                                      ajuste supervisionado após o
                                      treinamento inicial.

  RLHF                                Reinforcement Learning from Human
                                      Feedback, técnica de
                                      pós-treinamento baseada em feedback
                                      humano.
  -----------------------------------------------------------------------
